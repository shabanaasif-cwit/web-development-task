## v1.1.0 - 2025-11-10
`(D) 2025-11-10`

### Added
- Category-based routing with dynamic pages using `/:category` (for example: `/business`, `/technology`, `/sports`).
- Dedicated informational pages: `Contact`, `About`, `Privacy`, and `Terms`.
- Context-based global state via `NewsProvider` for posts, loading/error state, search query, selected category, and refresh behavior.
- Responsive header navigation with a mobile menu drawer and category links.
- Mobile-specific search bar layout.
- Post listing enhancements with sort controls (`Newest`, `Oldest`, `Title A-Z`, `Title Z-A`) and pagination.
- Card UX improvements including fallback image support, title/excerpt truncation, and open-in-new-tab action.

### Changed
- Migrated data fetching flow from direct `fetch` usage to Axios-based service abstraction.
- Refactored app data flow to reduce prop drilling and centralize state in Context API.
- Updated category handling so URL category and selected state stay in sync.
- Improved main layout structure (`min-h-screen` + `flex` shell) so footer placement remains consistent across short/empty views.

### Fixed
- Fixed Post page rendering issue introduced during refactoring.
- Fixed category navigation behavior in header, including mobile menu handling.
- Fixed empty state visual scaling/centering issues.
- Fixed loader/footer spacing behavior to prevent layout jump during loading/empty states.
- Fixed minor footer and UI polish issues from recent layout updates.

### Security
- No dedicated security updates in this release.

### Internal
- Added Axios instance configuration and reusable API service layer.
- Continued component cleanup and consistency updates across header, footer, cards, and post page modules.
- Retained utility scaffolding for retry-enabled fetch workflows and modular common UI states.
